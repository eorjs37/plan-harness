# 겨울 신규채널 안내 배너 요구사항

## 목표와 범위

매장 점주에게 겨울 신규채널을 알리고 홈 화면의 ‘추천채널’ 영역으로 안내한다. 이번 작업에는 홈 화면의 스와이퍼 형태 레이어 팝업과 ‘추천채널’ 영역으로의 이동을 포함한다. [기능 요청서](request.md), [분석서의 답변](analysis.md#남은-질문)

## 사용자 흐름

1. 매장 점주가 홈 화면에 진입한다.
2. 홈 화면에 스와이퍼 형태의 레이어 팝업이 표시된다.
3. 점주가 겨울 신규채널 안내를 누르면 같은 홈 화면의 ‘추천채널’ 영역으로 이동한다.

## 정책과 예외

- 매장 점주에게 2026년 12월 26일까지(당일 포함) 겨울 신규채널 안내를 노출한다.
- 겨울 신규채널 안내는 스와이퍼의 첫 번째 항목에 표시한다.
- 홈 화면에는 ‘추천채널’ 영역이 항상 표시된다.
- 방문 유도 효과에 대한 별도 측정은 요구하지 않는다.

## 요구사항을 충족했는지 확인하는 방법

- 노출 기간에 매장 점주가 홈 화면에 진입하면 레이어 팝업의 스와이퍼 첫 번째 항목에 겨울 신규채널 안내가 표시된다.
- 2026년 12월 27일부터 겨울 신규채널 안내가 표시되지 않는다.
- 점주가 겨울 신규채널 안내를 누르면 같은 홈 화면의 ‘추천채널’ 영역으로 이동한다.

# 겨울 신규채널 안내 실행 과제

## 홈 레이어 팝업에 겨울 신규채널 안내 추가

**관련 요구사항** — [사용자 흐름](requirements.md#사용자-흐름), [정책과 예외](requirements.md#정책과-예외)

**할 일** — 매장 점주가 홈 화면에 진입할 때 표시되는 레이어 팝업의 스와이퍼에 겨울 신규채널 안내를 추가한다. 안내를 첫 번째 항목에 배치한다.

**완료 확인 방법** — 노출 기간에 매장 점주가 홈 화면에 진입하면 스와이퍼의 첫 번째 항목에 겨울 신규채널 안내가 표시된다.

## 추천채널 영역으로 이동 연결

**관련 요구사항** — [사용자 흐름](requirements.md#사용자-흐름)

**할 일** — 겨울 신규채널 안내를 누르면 같은 홈 화면의 ‘추천채널’ 영역으로 이동하도록 연결한다.

**먼저 필요한 일** — 홈 레이어 팝업에 겨울 신규채널 안내를 추가한다.

**완료 확인 방법** — 점주가 겨울 신규채널 안내를 누르면 같은 홈 화면에서 ‘추천채널’ 영역을 볼 수 있다.

## 겨울 신규채널 안내 노출 종료일 적용

**관련 요구사항** — [정책과 예외](requirements.md#정책과-예외)

**할 일** — 겨울 신규채널 안내의 노출 종료일을 2026년 12월 26일로 설정한다. 종료일 당일을 포함한다.

**완료 확인 방법** — 매장 점주가 홈 화면에 진입하면 2026년 12월 26일에는 겨울 신규채널 안내가 표시되고 12월 27일부터는 표시되지 않는다.

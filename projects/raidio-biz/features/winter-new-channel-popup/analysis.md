# 겨울 신규채널 안내 배너 요청 분석

## 검토 요약

매장 점주에게 홈 화면에서 겨울 신규채널을 알리고 방문을 유도하는 배너를 추가한다. 점주가 홈 화면에서 배너를 볼 수 있고, 배너를 누르면 지정된 겨울 신규채널 화면으로 이동하는지 확인한다. [기능 요청서](request.md)

## 문제와 기대 결과

BO팀은 매장 점주가 겨울 신규채널을 쉽게 발견하고 방문하기를 기대한다. 안내 방식은 테마 팝업에서 홈 배너로 변경됐다. 변경 사유는 확인이 필요하다.

## 현재 흐름과 근거

점주가 현재 신규채널을 발견하는 경로와 홈 화면의 기존 배너 구성은 요청서에서 확인되지 않는다. 배너 배치를 정하기 전에 홈 화면과 기존 채널 진입 경로를 확인한다.

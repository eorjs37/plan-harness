# 프로젝트별 작업현황표 내보내기

저장소 루트에서 다음과 같이 호출한다.

```text
$export-project-status raidio-biz status-reports
$export-project-status all status-reports
```

첫 번째 인자는 `projects/` 아래의 프로젝트 폴더명 또는 전체 프로젝트를 뜻하는 `all`이다. 두 번째 인자는 저장소 루트 기준 출력 폴더이며, 생략하면 `status-reports`를 사용한다. 지정한 프로젝트가 없거나 출력 경로가 저장소 밖을 가리키면 경로를 안내하고 중단한다.

1. 대상 프로젝트의 `project.md`와 `features/` 아래 각 기능 폴더의 기존 산출물을 확인한다. 보고 기준일과 프로젝트명을 명시한다.
2. 기능마다 `request.md`, `analysis.md`, `requirements.md`, `tasks.md` 4종의 작성 여부를 확인한다. 파일이 없거나 비어 있거나 양식만 남아 있으면 미작성으로 집계한다. 실제 내용이 작성된 문서는 작성으로 집계하고, 남은 결정이나 검토 사항이 있으면 별도로 적는다.
3. 기능별로 **기능 | 작성률 | 작성된 산출물 | 미작성 산출물**을 표시한다. 작성률은 작성 문서 수를 4로 나눈 백분율과 건수를 함께 표시한다. 프로젝트 전체 작성률은 작성 문서 수 합계를 전체 대상 문서 수로 나누고 정수로 반올림한다. 등록된 기능이 없으면 ‘해당 없음’으로 표시한다. 집계 범위는 저장소의 기획 Markdown 4종이다.
4. 출력 폴더를 필요에 따라 만들고 프로젝트마다 `<프로젝트>-status.md` 한 파일을 저장한다. 재실행하면 같은 현황표를 갱신한다. 작성된 산출물은 보고서 위치 기준 상대 경로로 연결하고, 작성한 현황표 경로를 알려준다.

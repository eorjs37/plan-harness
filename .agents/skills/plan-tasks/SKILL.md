# 기능 실행 과제 정리하기

저장소 루트에서 `$plan-tasks raidio-biz winter-new-channel-popup`처럼 호출한다. 첫 번째 값은 프로젝트 폴더명이고 두 번째 값은 기능 폴더명이다.

1. 인자가 두 개이며 각각 영문 소문자와 숫자로 이루어진 단어를 하이픈으로 연결한 이름인지 확인한다. 형식이 맞지 않으면 호출 예시를 안내하고 중단한다.
2. `projects/<프로젝트>/project.md`, `projects/<프로젝트>/features/<기능>/requirements.md`, `templates/tasks.md`를 읽는다. 문서를 찾을 수 없거나 요구사항이 비어 있으면 필요한 파일이나 내용을 안내한다.
3. 확정된 요구사항을 각각 완료 여부를 확인할 수 있는 과제로 나눈다. 간단한 변경은 한 과제로 묶는다. 양식에 따라 과제명, 관련 요구사항의 제목이나 번호, 할 일, 완료 확인 방법을 적고, 선행 작업이나 결정이 있으면 해당 과제에 기록한다. 미확정 정책은 확인할 결정으로 남긴다.
4. 같은 기능 폴더의 `tasks.md`에 과제를 작성한다. 기존 문서가 있으면 진행 상태와 유효한 결정을 보존하며 관련 과제만 갱신한다. 저장 경로와 과제 진행에 필요한 미결 사항을 알려준다. 작업 범위는 과제 문서 작성까지다.

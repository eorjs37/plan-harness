# 기능 요구사항

요청서와 분석서에서 확인한 내용을 바탕으로 작성합니다. 각 항목의 ‘여기에 입력’을 답변으로 바꾸세요. 간단한 변경은 필요한 항목만 작성하고, 아직 결정할 내용은 마지막에 남깁니다.

## 목표와 범위

누구를 위해 무엇을 바꾸나요? 이번에 포함할 내용과 제외할 내용은 무엇인가요? 작업 순서나 성공 지표가 정해졌다면 함께 적어주세요.

여기에 입력

## 사용자 흐름

사용자가 어디에서 시작해 무엇을 하고 어떤 결과를 보나요? 화면 이동이나 선택에 따라 흐름이 나뉘면 각 경로를 순서대로 적어주세요.

여기에 입력

## 정책과 예외

누구에게 언제 적용하나요? 조건에 따라 어떤 동작을 하나요? 해당되는 경우 취소, 오류, 데이터 없음 등의 상황에서 어떻게 처리하는지도 적어주세요.

여기에 입력

## 요구사항을 충족했는지 확인하는 방법

어떤 상황에서 사용자가 무엇을 하면 어떤 결과가 나와야 하나요? 예를 들어 ‘매장 점주가 홈 화면에서 겨울 신규채널 배너를 누르면 지정된 채널 화면이 열린다’처럼 적어주세요.

여기에 입력

## 결정이 필요한 사항

아직 무엇을 정해야 하나요? 누구에게 묻거나 어떤 자료를 확인하면 되나요?

여기에 입력

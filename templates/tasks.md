# 기능 실행 과제

[요구사항 문서](requirements.md)를 읽고 할 일을 나눕니다. 과제마다 아래 양식을 복사해 ‘여기에 입력’을 바꾸세요. 간단한 변경은 과제 하나로 정리해도 됩니다.

## 과제명

어떤 작업을 하나요? 예를 들어 ‘겨울 신규채널 안내 노출 종료일 적용’처럼 적으세요.

여기에 입력

**관련 요구사항**

이 과제가 반영하는 요구사항의 제목이나 번호를 적으세요.

여기에 입력

**할 일**

어디에서 무엇을 변경하나요?

여기에 입력

**먼저 필요한 일 (해당하는 경우)**

이 과제에 앞서 끝내야 할 작업이나 확인할 결정이 있나요?

여기에 입력

**완료 확인 방법**

어떤 조건에서 무엇을 확인하면 작업이 끝났다고 볼 수 있나요? 예를 들어 ‘12월 26일에는 안내가 표시되고, 12월 27일부터 표시되지 않는다’처럼 적으세요.
